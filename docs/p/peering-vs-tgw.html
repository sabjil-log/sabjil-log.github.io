❯ VPC가 늘어나면 연결이 지옥이 된다 — 피어링 vs Transit Gateway

한 줄 요약: 피어링은 VPC 둘 사이의 직통 전화선, Transit Gateway(TGW)는 모두가 꽂히는 중앙 교환기입니다. VPC가 N개면 피어링은 연결이 N×(N−1)/2개로 폭발하고(10개면 45개), TGW는 N개로 끝나죠 — MCP 글의 그 M×N 문제가 네트워크에서 재현되는 겁니다.

피어링 — 직통선의 미덕과 한계

피어링은 VPC 두 개를 잇는 가장 단순한 방법입니다. 요청·수락 → 양쪽 라우팅 테이블에 서로의 대역 추가(서브넷 글의 그 "경로가 정체를 정한다" 원칙) → 끝. 중간 장비가 없어 지연·비용 오버헤드도 최소죠.

한계는 두 가지가 본질입니다.

① 전이 불가(non-transitive). A–B, B–C가 피어링돼 있어도 A에서 C로는 못 갑니다. 전화선은 건너 타지지 않아요 — B가 중계해주지 않습니다(그렇게 하라고 라우팅을 꺾어도 피어링은 남의 트래픽을 전달하지 않음). A–C가 필요하면 직통선을 또 놓아야 하죠.

② 그래서 연결 수 폭발. 모든 VPC가 서로 통해야 하면 완전 그물(full mesh)이 필요하고, 그 수가 N×(N−1)/2. VPC 4개면 6개 — 견딜 만합니다. 10개면 45개 — 각 연결마다 양쪽 라우팅 테이블 관리가 따라오니, 관리하는 건 연결 45개가 아니라 라우팅 항목 수백 개예요. VPC 하나 추가할 때마다 기존 전부와 선을 놓고 라우팅을 고치는 세상이 됩니다.

Transit Gateway — 교환기 모델

TGW는 발상을 바꿉니다 — 서로 잇지 말고, 전부 하나의 허브에 꽂아라.

  • VPC마다 TGW에 연결(attachment) 하나. N개 VPC = N개 연결. 새 VPC 추가 = 연결 1 + 라우팅 몇 줄.
  • 전이가 됩니다 — 허브니까요. A→TGW→C가 기본 동작.
  • 온프레미스 VPN·전용선도 같은 허브에 꽂혀서, "본사↔모든 VPC"가 연결 하나로 해결됩니다. 하이브리드가 얽히는 순간 TGW의 가치가 급등하는 이유.
  • TGW 자체의 라우팅 테이블로 "누가 누구와 통할 수 있는지"를 중앙에서 통제 — 개발 VPC들끼리는 차단하고 공용 서비스 VPC만 열어주는 식의 세그먼테이션이 표 하나로 됩니다. 전화선 45개 시절엔 불가능했던 관제죠.

대가도 명확합니다 — 시간당 + 처리 GB당 요금(NAT 글의 그 이중 과금 구조와 같은 문법)이 붙고, 홉이 하나 늘어 약간의 지연이 추가됩니다. 대량 트래픽이 상시 흐르는 두 VPC라면, TGW를 쓰더라도 그 구간만 피어링 직통선을 병행하는 하이브리드가 실전 답이 되기도 해요.

갈아타는 시점 — 숫자보다 신호

경험칙은 "VPC 4~5개 또는 온프레미스 연동 등장"인데, 숫자보다 정직한 신호가 있습니다.

  • 새 VPC 붙이는 작업이 반나절짜리 라우팅 수술이 됐다
  • "A에서 C 되나요?"에 그림을 그려봐야 답할 수 있다
  • 계정·조직이 나뉘어 VPC가 계속 늘어날 예정이다 (MSP라면 사실상 기본값)
  • 온프레미스/VPN이 여러 VPC와 통해야 한다

NCP도 같은 그림입니다 — VPC Peering이 있고, 허브 역할의 Transit VPC/전용 연결 구성이 대응 개념(이름 지도 글의 원칙대로 세부 스펙은 문서 재확인). 개념 선택 기준은 벤더 불문 동일해요.

두 방식 공통의 함정: CIDR 중복

피어링이든 TGW든 대역이 겹치는 VPC는 못 잇습니다. 라우팅은 목적지 대역으로 길을 고르는데, 양쪽이 다 10.0.0.0/16이면 "10.0.0.5로 가라"가 우리 집인지 남의 집인지 구분이 안 되니까요. 그리고 이 문제는 나중에 못 고칩니다 — VPC 대역 변경은 사실상 재구축이라서요.

그래서 연결 계획이 조금이라도 있다면 처음부터 VPC별 대역 설계(예: VPC마다 /16을 겹치지 않게 배정, 환경별 대역 규칙)가 피어링/TGW 논쟁보다 먼저입니다. 오늘 글에서 하나만 가져간다면 이겁니다 — 연결의 자유는 CIDR 계획에서 나온다.

한 줄 정리

둘이면 피어링(직통선), 여럿이면 TGW(교환기). 피어링은 전이 불가 + N² 폭발, TGW는 연결 N개 + 중앙 통제 + GB당 요금. 갈아탈 신호는 "새 VPC 붙이기가 수술이 될 때" — 그리고 어느 쪽이든, 겹치지 않는 CIDR 설계가 모든 것의 선행 조건입니다.
