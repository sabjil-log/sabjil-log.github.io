> **한 줄 요약:** 권한 숫자는 **읽기(4) + 쓰기(2) + 실행(1)의 합**이고, 그게 **소유자/그룹/그외** 세 자리로 반복됩니다. 755 = 소유자 7(4+2+1 전부) · 그룹 5(4+1 읽기+실행) · 그외 5. 외울 건 4·2·1 세 개뿐입니다.

## ls -l 이 보여주는 것부터

```bash
$ ls -l deploy.sh
-rwxr-xr-x  1 taewan devops  512 Jul 29 09:00 deploy.sh
```

맨 앞 한 글자(파일 종류) 빼고 아홉 글자를 **세 글자씩** 끊어 읽습니다.

```
rwx  r-x  r-x
└소유자 └그룹 └그외(others)
```

각 칸은 r(읽기), w(쓰기), x(실행)가 있냐 없냐(-). 이걸 숫자로 바꾸는 규칙이 **r=4, w=2, x=1** — 그래서 `rwx`=7, `r-x`=5, `r--`=4. 위 파일이 곧 755입니다.

## 왜 하필 4, 2, 1인가

이진수 자릿값이기 때문입니다. 세 비트 `rwx`를 각각 켜고 끄는 스위치로 보면:

```
r w x
1 0 0  = 4   (읽기만)
0 1 0  = 2   (쓰기만)
0 0 1  = 1   (실행만)
1 1 1  = 4+2+1 = 7
1 0 1  = 4+1   = 5
1 1 0  = 4+2   = 6
```

합이 겹치지 않게 설계된 덧셈이라, **숫자 하나가 조합 하나와 정확히 1:1**입니다. 6을 보면 "읽기+쓰기, 실행은 없음"이 역산되죠.

## 자주 쓰는 조합, 이제 외우지 말고 만들기

- **755** — 소유자 전부 / 남은 읽고 실행만. **실행 파일·스크립트·디렉토리**의 표준.
- **644** — 소유자 읽고 쓰기 / 남은 읽기만. **일반 파일**(설정, HTML)의 표준.
- **600** — 소유자만 읽고 쓰기, 남은 아무것도. **비밀 파일**(키, .env)의 표준. SSH가 `~/.ssh/id_rsa`에 이걸 강제하는 이유입니다 — 남이 읽을 수 있는 개인키는 키가 아니니까요.
- **777** — 전원 전부 허용. "일단 되게" 하고 싶을 때의 유혹인데, **웹서버가 쓸 수 있는 실행 파일**은 공격자에게도 그렇습니다. 777이 답인 상황은 거의 없고, 대부분 소유자를 고치는 게(chown) 진짜 답입니다.

## 디렉토리의 x는 다르다 — 함정 하나

파일의 x는 실행인데, **디렉토리의 x는 "통과"**입니다.

- 디렉토리 r = 목록 보기(ls)
- 디렉토리 x = **그 안으로 들어가기(cd), 안의 파일에 접근하기**

그래서 디렉토리에 r만 주고 x를 빼면(644), 목록은 이론상 보이는데 안의 파일은 못 여는 기묘한 상태가 됩니다. **디렉토리는 5(r-x) 또는 7(rwx)** — 4로 끝나는 디렉토리 권한은 거의 항상 실수예요. "웹서버가 파일을 못 읽어요"의 단골 원인이 파일 권한이 아니라 **경로 중간 디렉토리의 x 누락**이기도 합니다.

```bash
namei -l /var/www/html/index.html   # 경로의 각 단계 권한을 한 줄씩 — 범인 색출기
```

## 실전 명령

```bash
chmod 644 config.yml          # 숫자로 지정
chmod +x deploy.sh            # 기호로: 실행 비트만 추가 (지금 상태에 +)
chmod u=rw,go=r config.yml    # 기호로: 소유자 rw, 그룹·그외 r
chmod -R 755 /var/www/html    # 재귀 — 단, 아래 주의

stat -c "%a %n" *             # 파일들의 숫자 권한 한눈에
```

`-R 755`의 함정: 디렉토리엔 맞지만 **일반 파일에까지 실행 비트**가 붙습니다. 파일 644 / 디렉토리 755를 한 번에 하려면:

```bash
find /var/www/html -type f -exec chmod 644 {} +
find /var/www/html -type d -exec chmod 755 {} +
```

## 한 줄 정리

권한 숫자는 **r4 + w2 + x1의 덧셈 × (소유자·그룹·그외)**. 실행물·디렉토리 755, 일반 파일 644, 비밀 600 — 그리고 디렉토리의 x는 "통과"라는 것과, 안 열리면 `namei -l`로 경로 전체를 훑는 것까지가 한 세트입니다.
